# Databricks SQL Outline

Adds Databricks SQL table symbols to VS Code's built-in Outline view. It recognizes `CREATE TABLE`, `CREATE OR REPLACE TABLE`, and `CREATE TABLE IF NOT EXISTS` declarations, including qualified and backtick-quoted Unity Catalog names.

## Installation

Install [Databricks SQL Outline](https://marketplace.visualstudio.com/items?itemName=praveen-balanagendra.databricks-sql-outline) from the VS Code Marketplace, or search for "Databricks SQL Outline" in the Extensions view (`Ctrl+Shift+X`).

## Usage

1. Open a `.sql` file.
2. Open View > Open View > Outline. Use the Outline menu's Sort By > Name for alphabetical ordering.
